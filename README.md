# 창고 재고 불출 웹페이지

## 실행
- Windows: `실행.bat` 더블클릭 (Python 3.10 이상 필요) → 브라우저에서 http://localhost:8080
- 같은 사내망의 다른 PC/휴대폰: `http://<이 PC의 IP>:8080`

## 저장 파일 (모두 data 폴더)
- `재고현황.xlsx` : 제품코드, 제품명, 제조사, 적재위치, 현재고수량, 안전재고, 긴급도, 최종변경일시
- `변경로그.xlsx` : 일시, 구분, 제품명, 제조사, 적재위치, 변경전 재고, 변경수량, 변경후 재고, 담당자, 비고, 제품코드
- `접속기기.xlsx` : 기기코드, 이름, 최초IP, 최근IP, 최초등록일시, 최근접속일시, 브라우저
- `발주요청.xlsx` : 요청번호(R00001…), 요청일시, 제품, 요청시 재고, 요청수량, 요청자, 비고, 상태(요청/완료/취소), 처리일시, 처리자, 기기코드
- `images/<제품코드>.jpg` : 제품 사진 (최대 1200px), `images/thumbs/` : 목록용 작은 사진
- 서버 실행 중 Excel 파일을 열어 두면 저장이 막힙니다(Windows 파일 잠금). 확인은 웹의 다운로드 버튼으로 받은 사본을 보세요.

## 화면
- 재고현황: 사진 · 제품명[제조사] · 적재위치 · 현재고 · 안전재고 · 상태(정상/부족). 부족 품목이 맨 위.
  - 제품 클릭 → 입고/출고, 기준수정(안전재고·긴급도 A/B/C), 사진 등록(휴대폰 촬영 가능), 적재위치 변경, 라벨 인쇄
  - 바코드 칸: USB 바코드 스캐너로 스캔(또는 제품코드 입력 후 Enter) → 해당 제품 입고/출고 창이 열림
- 제품코드: P00001부터 자동 부여. 바코드 라벨(Code128)은 ‘바코드 라벨’ 메뉴(전체) 또는 제품 창의 ‘라벨 인쇄’(개별)
- 엑셀 일괄입력: 양식 다운로드 → 수정 후 업로드 → 미리보기 → 적용. 안전재고·긴급도 열은 선택(비우면 유지)

- 기기 등록: 처음 접속한 기기(브라우저)는 화면이 흐려지고 이름 입력창이 뜸 → 확인 후 사용 가능. 쿠키(wh_device, 10년)로 기억. 브라우저를 바꾸거나 쿠키를 지우면 다시 입력. 등록된 이름이 담당자 기본값.
- 제조사 [Molex] 등 클릭 → 그 제조사 제품 목록(모델명·적재위치·현재고) → 제품 클릭 시 입고/출고/발주 창
- 사진 없는 제품: 목록의 📷 또는 제품 창 사진칸에서 바로 촬영/파일선택
- 재고부족 탭: 현재고 < 안전재고 품목만. 발주요청 탭: 요청중/완료/취소 관리 (완료해도 재고는 안 바뀜, 입고는 따로)
- 주황색 '발주' 버튼: 수량 입력 후 발주요청 등록 (발주로 열면 부족분이 기본 수량)
